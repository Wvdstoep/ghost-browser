MCP setup

Connect Codex or Claude Code to this Ghost Browser's internet tools. A browser API key grants full access to this instance, so keep it private.

1. Server URL and key

Sign in to this Ghost Browser before revealing its key. Keep the key out of project files and commits.


  

  

    
2. Codex

    
Set GHOST_BROWSER_KEY in the environment that starts Codex. Add this to ~/.codex/config.toml, then start a new session.

    

    
  

  

    
3. Claude Code

    
Replace YOUR_GHOST_BROWSER_KEY with your key and run this command in a private terminal.
